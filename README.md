# Python Password Generator

A beginner Python project that generates secure random passwords using Python's built-in `secrets` and `string` modules.

## Features

- Generates passwords between 8 and 64 characters.
- Includes at least one uppercase letter.
- Includes at least one lowercase letter.
- Includes at least one digit.
- Includes at least one special character.
- Uses Python's `secrets` module for secure random character selection.
- Validates password length.

## Technologies Used

- Python 3
- secrets module
- string module
- Loops and conditional statements
- String operations
- Generator expressions (`any()`)

## How to Run

1. Install Python 3.
2. Clone this repository.
3. Open the project folder.
4. Run:

```bash
python password_generator.py
```

5. Enter a password length between 8 and 64.

## Learning Objectives

This project demonstrates practical applications of Python variables, data types, loops, conditions, string methods, built-in modules and secure random selection.
